# @ai-duel/legacy-client

黑客松版客户端，原来叫 `packages/client`。**已经冻结**。

- **不加功能。** 只修会让线上崩掉的问题。新界面、新交互一律做在正式版的 `packages/client` 和 `apps/web` 里。
- **不进 lint。** 这一版是几千行的单文件加一整个全局 css，按正式版的 lint 规则（单文件 400 行、依赖方向、无全局样式）根本过不了，所以直接排除在外。只保留 `typecheck` 和现有的测试。
- **仍然是线上版本。** 部署流水线构建的就是这个包，`packages/server` 的 `assets.directory` 也指向它的 `dist`。迁移第 38 条追平之前不能删。
- **迁移第 38 条时整包删除**（见 `docs/正式版架构.md` 第 8 节）。

## 它现在的用处：新客户端的行为规格

正式版是重写不是迁移，但**手感要一比一复刻**。动画时长、缓动曲线、各步之间的等待、
一个事件里多个动作的先后顺序，全部从这里的代码抄，不要凭感觉重新拍数字。
对应的界面说明见 `docs/architecture.md`（同样已冻结）。

抄的时候只抄「什么时候发生、持续多久、按什么顺序」，不要抄实现——
DOM 元素、CSS 类名、GSAP Flip 这些在正式版里都不存在了。
